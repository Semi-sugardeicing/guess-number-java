# Java 猜数字游戏

一个用 Java 写的命令行猜数字小游戏，**不用联网，只用 JDK 自带的东西**。

## 玩法

启动以后先设三个数：起始数字、末尾数字、还能猜几次。设完程序会在你给的范围内偷偷选一个，然后你就开始猜，每次它会告诉你猜大了还是猜小了。猜中会有提示，次数用光会把答案告诉你。中途不想玩了，输入 Q 直接退出。

```
请输入起始数字：1
请输入末尾数字：100
请输入猜的次数：8
请猜一个数字 (范围 1 ~ 100，按 Q 退出): 50
猜大了！
请猜一个数字 (范围 1 ~ 100，按 Q 退出): 25
猜小了！
```

## 怎么运行

需要电脑上装了 Java（JDK 或 JRE 都行，8 以上）。

```bash
javac Main.java
java Main
```

第一条是编译，会生成一个 Main.class 文件；第二条是运行。以后只改代码不编译的话，记得重新打一次第一条。

## 当前已知问题

猜最后一手如果没猜中，会先跳一行红色报错，然后才打印「次数用光了」和正确答案。不影响继续玩，原因是次数用完之后又去读了一次输入。修法很简单，留待之后改。
